3. Dictionaries

Extremely common for counting/grouping manually.

d = {"a": 1, "b": 2}

d["a"]

d.get("c", 0)

d["c"] = 3

for key in d:
    print(key)

for key, value in d.items():
    print(key, value)

Frequency counting:

counts = {}

for x in xs:
    counts[x] = counts.get(x, 0) + 1

Or:

from collections import Counter

counts = Counter(xs)

4. Sets

Useful for unique values / membership / intersections.

s = set(xs)

x in s

s.add(5)

a | b       # union
a & b       # intersection
a - b       # difference

Unique values:

len(set(xs))

5. Strings

s = "hello world"

s.lower()
s.upper()
s.strip()

s.split()
s.split(",")

",".join(["a", "b", "c"])

s.startswith("hello")
s.endswith("world")

"a" in s

6. Sorting with custom keys

Very useful.

pairs = [("a", 3), ("b", 1), ("c", 2)]

sorted(pairs, key=lambda x: x[1])

Descending:

sorted(pairs, key=lambda x: x[1], reverse=True)
